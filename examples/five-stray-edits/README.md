# Five stray edits

Run `node examples/five-stray-edits/run-examples.mjs` to exercise the actual conservation checks and checkpoint recovery in an isolated temporary workspace. Each result includes its input and attempted output. Pass `--json` to inspect all snippets and returned violation codes.

The examples cover a removed sibling export, a weakened test, a changed JSON Schema, drift outside a Markdown section, and recovery after a shell deletes a test.
